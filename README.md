# Student Housing Platform

## Overview
A full-stack housing search platform designed to help students browse and filter available accommodations.

The project focused on usability and reliability rather than visual complexity.

---

## Problem
Students searching for housing typically rely on scattered listings, social media posts, and spreadsheets.

There is no structured way to:
- filter listings
- compare options
- browse geographically

---

## Features
- listing browsing
- filtering by criteria
- structured property data
- map-based navigation
- user-focused search flow

---

## My Contributions
- backend filtering logic
- data handling and validation
- search workflow design
- integrating map-based search

---

## Design Considerations
Instead of optimizing for features, the focus was:

clarity > complexity

The system prioritizes predictable behavior and easy navigation.

---

## What I Learned
Building software for real users is different from assignments.  
Reliability, clear workflows, and edge-case handling matter more than technical sophistication.
